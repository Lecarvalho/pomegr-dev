# Get help with Pomegr

Start with the guide at [pomegr.com/docs](https://pomegr.com/docs).

- **A bug or a question:** [open an issue](https://github.com/Lecarvalho/pomegr-dev/issues/new/choose) in this repository.
- **Something you cannot share in public:** write to the [contact address](#contact).
- **A security problem:** follow [SECURITY.md](SECURITY.md).

Say which Pomegr version you use, and whether it is the installed or the portable build. The
About page in Settings shows the version.

## Keep your work out of an issue

Issues are public. Pomegr shows your local coding sessions, so a screenshot or a copied value
can hold more than you expect. Never post prompts, responses, transcripts, credentials, file
paths, or repository names. Describe what you saw, or draw it with invented values.

## Contact

Write to [contact@pomegr.com](mailto:contact@pomegr.com).
