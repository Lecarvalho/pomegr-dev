# Legal

Each Pomegr release carries its own terms. They are not files in this repository: each
[release](https://github.com/Lecarvalho/pomegr-dev/releases) attaches them next to its
installer, from `v0.10.0`. Read the files attached to the release that you downloaded. The terms
of one release do not change another. A copy also comes with the app: open Settings, then About.

| File in a release | What it holds |
| --- | --- |
| `LICENSE` | The terms for Pomegr in that release |
| `NOTICE` | The copyright statement for that release |
| `SOURCE.md` | Where to get the source of third-party components |
| `THIRD_PARTY_NOTICES.md` | The third-party components in that release, with their license texts |
| `TRADEMARKS.md` | How you may use the Pomegr name and visual identity |

Third-party components stay under their own licenses. Where a license asks for the source of a
component, the release attaches it.

The pages in this repository are not licensed for reuse. You may link to them and quote them.

The exception is the plugin files: `plugins/`, `.claude-plugin/marketplace.json`, and
`.agents/plugins/marketplace.json`. Pomegr's own code in these files is under the MIT license.
Each plugin folder has its `LICENSE` and its `THIRD_PARTY_NOTICES.md`, which lists the packages
that its bundles hold. These files apply to any copy of the plugins, including GitHub's "Source
code" archives. The MIT license gives no right to the Pomegr name or the icon in each plugin.
