# Legal

Each Pomegr release carries its own terms. Read the files attached to the release that you
downloaded. The terms of one release do not change another.

| File in a release | What it holds |
| --- | --- |
| `LICENSE` | The terms for Pomegr in that release |
| `NOTICE` | The copyright statement for that release |
| `SOURCE.md` | Where to get the source of third-party components |
| `THIRD_PARTY_NOTICES.md` | The third-party components in that release, with their license texts |
| `TRADEMARKS.md` | How you may use the Pomegr name and visual identity |

Third-party components stay under their own licenses. Where a license asks for the source of a
component, the release attaches it.

The pages in this repository are not licensed for reuse. You may link to them and quote them.
